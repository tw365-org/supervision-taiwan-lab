# AI 模擬視覺實驗室｜Supervision 應用概念

## 範圍與事實邊界 / Scope

品牌為 **AI 模擬視覺實驗室**；英文為 **AI Simulation Vision Lab**，英文文件標題為 `AI Simulation Vision Lab | Supervision concepts`。既有網域、GitHub 與上游來源 URL 不變。原研究 `SUPERVISION_台灣應用_PLAN.md` 的正式標題與來源名稱不改。

這是獨立的 React + TypeScript + Vite 互動概念網站，不是 Roboflow 官方產品，不執行 Python、Supervision 或模型。研究沿用原計畫的公開來源及 0.31.2 基準，保留技術、授權與未驗證邊界。20 個應用**全部能在第一節操作**，不是僅有介紹。推薦順序仍為 #7 排隊、#1 機車空位、#12 人車交會，之後以完整原生選單呈現其餘應用。

All data is deterministic, synthetic and local. No cameras, uploads, inference services, external data APIs, accuracy claims or field measurements. Potential buyers, recommendations and business models remain hypotheses. Source links and all 20 bilingual field-validation and safety limitations remain visible. System fonts avoid third-party font requests.

## 20種模擬的決策語意

所有數字都是畫面合成資料，不是模型結果。每項有三個具名情境，控制參數不共用隱含語意。靜態商品／樣本情境不假裝有時間序列；步數仍可選擇，只有明確設定為動態的物件或狀態隨步數變化。

| 原計畫編號 | 圖面與讀值                               | 專屬互動與邊界                                                                                              |
| ---------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 1          | 12格機車，占用／已確認空格／遮擋未知     | 調整低空位提醒格數；未知格不算空位，也不強判占用，不辨識車牌。                                              |
| 2          | 左／直／右路徑，機車或汽車及追蹤片段     | 選擇觀測轉向；第8步完成入口→出口才計事件，不用當下占用代替轉向量。                                          |
| 3          | 卸貨車、連續占用秒數與停留事件數         | 每步5秒，調整調度門檻；離開清零、第6步再進入另計第二次事件，不裁罰。                                        |
| 4          | 兩個候車區當下人數、獨立進出觀測線       | 選區比較；移動人物座標真正跨過線才計事件，另列可核對的步數歷史；不是路線需求或候車時間。                    |

## 模組、介面與在地化

- `src/lab.ts` 定義 `LabDemo` 的20個穩定ID、原研究編號、三種狀態、控制範圍／初值、讀值單位、場內標籤、專屬圖例與規則。文字以繁中／英文對照強制共存，`labCopy` 只選語系。
- `src/model.ts` 的純函式 `getScene(demo, scenario, frame, control, enabled)` 回傳物件、占用、未知、主／次讀值、提醒、不可觀測狀態與越線事件。沒有亂數、API、假準確率或通用佔用演算法充當所有用途。Bus/gate逐步重播同一座標函式，前後跨線才產生歷史事件。
- `src/Simulation.tsx` 保留前三推薦場景的品牌示意；`src/DomainScene.tsx` 繪製其餘17項的專屬場域及物件，無資料擷取和獨立計時。物件ID是臨時示意，不是身分。
- `src/App.tsx` 管理應用、情境、步數、控制、規則、播放與語系。切換應用回到該應用初始控制與第0步。重設停止播放、恢復本應用初值、情境0、規則啟用。關閉分析時兩讀值為破折號，不冒充正常或未共現。
- 穩定控制：`#lab-demo` 完整20項原生選單；`#scenario` 三種場景狀態；`#threshold` 有不同專屬標籤與單位的參數；`#frame` 0–11步滑桿；`[role=switch]` 規則開關。推薦頁籤支援左右鍵、Home、End。單步前進會暫停自動播放。
- `src/locales/types.ts`、`zh-TW.ts`、`en.ts` 保留完整站點、20項研究介紹、可及性與來源內容。舊有只適用三場景的重複lab讀值／規則字典已移除。
- 預設繁中；`localStorage["vision-lab-locale"]` 保存選擇，儲存不可用仍能切換；同步 `html.lang`、title、description。原來源與法規／模型限制未被互動模擬取代。
- `src/config.ts` 保留本站與上游兩組URL。`public/favicon.svg` 保留既有品牌圖；`index.html` 有明確icon link。正式站安全標頭仍由 `public/_headers` 提供，開發Vite不套用正式標頭。
